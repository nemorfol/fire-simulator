### Guida Rapida: Come Segnalare un Bug o Suggerire una Funzionalità su GitHub

Se trovi un errore (bug) nel simulatore o hai un'idea per una nuova funzionalità, il modo migliore per segnalarlo è tramite la sezione "Issues" (Problemi) del repository GitHub.

Segui questi passaggi:

1.  **Vai alla Pagina del Repository su GitHub:**
    Apri il tuo browser web e vai all'URL del progetto:
    `https://github.com/nemorfol/fire-simulator`

2.  **Accedi alla Sezione "Issues" (Problemi):**
    Sulla pagina del repository, cerca e clicca sulla tab (scheda) chiamata "**Issues**" (o "Problemi" se l'interfaccia di GitHub è in italiano). Questa tab si trova solitamente sotto il nome del progetto, insieme a "Code", "Pull requests", ecc.

3.  **Apri una Nuova "Issue":**
    Nella pagina delle "Issues", troverai un pulsante verde con l'etichetta "**New issue**" (Nuovo problema). Cliccaci sopra per aprire il modulo di segnalazione.

4.  **Compila il Modulo di Segnalazione:**
    Per aiutarci a capire e risolvere il problema il più rapidamente possibile, fornisci quante più informazioni dettagliate puoi:

    *   **Titolo (Title):** Un riassunto breve e chiaro del problema o della funzionalità (es. "Il grafico delle uscite mostra valori errati in fase di ritiro" o "Richiesta: Aggiungere simulazione Monte Carlo").

    *   **Descrizione (Write):** Qui devi essere il più dettagliato possibile. Se è un bug, includi:
        *   **Passaggi per Riprodurre il Bug:** Una lista numerata e precisa dei passaggi da seguire per far sì che il bug si manifesti. Questo è FONDAMENTALE!
            Esempio:
            1.  Apri il simulatore.
            2.  Imposta l'età iniziale a X e l'età di ritiro a Y.
            3.  Seleziona la checkbox "Fase di Ritiro".
            4.  Imposta la percentuale di prelievo al Z%.
            5.  Clicca su "Avvia Simulazione".
        *   **Comportamento Atteso:** Cosa ti aspettavi che succedesse (es. "Mi aspettavo che le uscite mostrassero il valore del prelievo del Z%").
        *   **Comportamento Attuale:** Cosa è successo realmente (es. "Invece, le uscite mostrano il valore delle spese ricorrenti precedenti").
        *   **Screenshot o Video (se applicabile):** Se possibile, allega un'immagine o un breve video che mostri il bug. Puoi trascinare i file direttamente nell'area di testo.
        *   **Informazioni sull'Ambiente:** Il tuo sistema operativo (es. Windows 10, macOS Ventura), il browser che stai usando (es. Chrome 115, Firefox 116) e la sua versione.

    *   **Per le Richieste di Funzionalità:** Descrivi l'idea, perché pensi sia utile e come potrebbe funzionare.

5.  **Invia la Segnalazione:**
    Una volta compilato, clicca sul pulsante verde "**Submit new issue**" (Invia nuovo problema).

Grazie per il tuo contributo! Ogni segnalazione aiuta a migliorare il simulatore.
